# Codex Quota

Небольшой нативный индикатор строки меню macOS для оставшейся квоты Codex.

[English](README.md) · [Лицензия MIT](LICENSE)

Два монохромных кольца: слева — **квота на 5 часов**, справа — **на неделю**. Точные проценты и время до сброса доступны по нажатию.

Неофициальный проект сообщества: не связан с OpenAI и не одобрен компанией. Меню и сообщения об ошибках сейчас на русском.

## Возможности

- Фиксированные 44 pt, включая отступы; нативный светлый/тёмный вид и сохранение расположения.
- Проценты в подсказке, раскрытое меню с временем до сброса и значения для средств доступности.
- Один постоянный локальный процесс `codex app-server` с переподключением при обрыве.
- Обновления по событиям и страховочная сверка раз в две минуты через то же соединение.
- Без анимаций, сторонних библиотек, телеметрии и хранения истории квот в виджете.

Отображается **квота аккаунта**, а не токены, стоимость или расход отдельного чата.

## Требования

- macOS 13 или новее. Проверено на Apple Silicon; Intel Mac не проверялись.
- Swift 6 или новее для сборки. Проверка: `swift --version`.
- Установленный Codex CLI с выполненным входом в аккаунт, который предоставляет лимиты на 5 часов и неделю. Подойдёт встроенный CLI приложения Codex/ChatGPT или отдельная установка.
- Интернет для получения актуальных лимитов через Codex.

В первом выпуске доступны исходники, без готового приложения для скачивания. Сборка:

```sh
git clone https://github.com/DOFomintsev/codex-quota.git
cd codex-quota
./scripts/build-app.sh
open "dist/Codex Quota.app"
```

Скрипт создаёт release-сборку и приложение с локальной ad-hoc подписью в `dist/`. Он не скачивает Codex, не устанавливает фоновый сервис и не включает автозапуск. После проверки приложение можно вручную перенести в «Программы».

Приложение **не подписано Apple Developer ID и не нотарифицировано Apple**. Нотарифицированного установщика в проекте нет.

Для разработки: `swift run CodexQuota`. Используй либо эту команду, либо собранное приложение, а не оба одновременно: иначе появятся дубли индикатора и процессов app-server.

## Как читать индикатор

| Вид | Значение |
| --- | --- |
| Сплошная дуга | Остаток квоты; полное кольцо — 100% |
| Пустое сплошное кольцо | Осталось 0% |
| Пунктирное кольцо | Для этого окна пока нет данных |
| Приглушённые кольца с маленькой точкой | Получить данные не удалось; сохранённые значения устарели |

Наведи курсор для просмотра процентов. Нажми для подробностей, времени до сброса, обновления и выхода.

Для перемещения удерживай **⌘ Command** и перетащи индикатор вдоль строки меню. Компактный размер уменьшает риск скрытия, но расположением управляет macOS: при нехватке места значки всё ещё могут исчезать. Закрепление слева от выреза камеры не реализовано.

## Как обновляются данные

Приложение открывает одно соединение с локальным app-server, получает снимок через `account/rateLimits/read` и слушает `account/rateLimits/updated`. Частичные уведомления объединяются с предыдущим снимком. Окна различаются по длительности; отдельные лимиты моделей не перезаписывают основную квоту Codex.

Отдельный app-server не гарантирует события о расходе из других процессов Codex, поэтому раз в две минуты выполняется сверка. Мгновенные обновления расхода в других клиентах не гарантируются. Ручное обновление использует открытое соединение; параллельные запросы объединяются.

Время ожидания ответа — 20 секунд. При обрыве выполняется переподключение с задержкой 5–60 секунд. После пробуждения Mac запрашиваются свежие данные. Минутный таймер только перерисовывает время до сброса, не выполняя сетевых запросов. При выходе через меню завершается собственный дочерний процесс.

Квота не сбрасывается по локальным часам: восстановление должен подтвердить сервер.

## Приватность и ограничения

Код виджета не читает историю чатов, `.env`, cookies, API-ключи или `auth.json`. Ответы с квотами не сохраняются, собственная аналитика не отправляется. Официальный дочерний процесс Codex использует свою обычную авторизацию и обращается к OpenAI; гарантии приватности виджета не распространяются на этот процесс.

Codex ищется в известных расположениях настольных приложений, `/opt/homebrew/bin`, `/usr/local/bin`, затем в `PATH`. Finder не наследует полный `PATH` интерактивного терминала: нестандартная установка вне этих путей может не обнаружиться.

Протокол app-server и доступность квот могут измениться после обновления Codex. Отсутствие или неподдерживаемый формат 5-часового окна вызывает ошибку, а не выдуманные значения. Аккаунты только с API-ключом и все виды подписок не проверялись.

## Проверки

Запускай из корня репозитория. Эти проверки локальные и не обращаются к аккаунту Codex:

```sh
swift run CodexQuota --self-test
swift run CodexQuota --icon-test
swift run CodexQuota --transport-test
```

Проверяются парсинг, частичные уведомления, длительности окон, состояния значка, поток сообщений, повторный запрос в том же процессе, переподключение и остановка. После `--icon-test` можно указать путь PNG для визуальной проверки всех состояний значка.

Проверки живых данных требуют авторизованного Codex и обращаются к сервису:

```sh
swift run CodexQuota --print-status
swift run CodexQuota --watch-status
```

Вторая команда наблюдает за обновлениями 130 секунд, включая страховочную сверку, затем завершается.

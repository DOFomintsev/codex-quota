# Codex Quota

Небольшой виджет в строке меню macOS, который показывает остаток лимитов аккаунта Codex. Первое кольцо — лимит на 5 часов, второе — недельный лимит.

[English version](README.md) · [Лицензия MIT](LICENSE)

Неофициальный проект сообщества. Он не связан с OpenAI и не одобрен компанией.

## Что показывает приложение

- Остаток лимита на 5-часовое и недельное окна.
- Процент использования и время сброса, если Codex прислал эти данные.
- Компактные кольца в строке меню и увеличенный виджет с подробностями.
- Отдельные состояния, если данные ещё не получены или последнее обновление не удалось.

Полное кольцо означает, что осталось 100%, пустое — что осталось 0%. Пунктирное кольцо означает, что данные ещё не поступали. Приглушённые кольца с точкой означают ошибку запроса: показанные значения могут быть устаревшими.

Наведите курсор, чтобы увидеть проценты. Нажмите на виджет, чтобы открыть подробности, выбрать **Обновить** или выйти. Удерживая **⌘ Command**, перетащите виджет, чтобы переместить его в строке меню. Итоговое расположение выбирает macOS; при нехватке места система может скрывать элементы.

## Как это работает

Codex Quota запускает локальный app-server Codex через уже установленный Codex и вашу текущую авторизацию. Виджет запрашивает лимиты аккаунта и слушает обновления. Активность в других окнах Codex не всегда передаёт обновление этому отдельному процессу, поэтому приложение дополнительно проверяет данные раз в две минуты.

Виджет не вычисляет время сброса по часам Mac — он ждёт данные от Codex. Если Codex недоступен, приложение сохраняет последние значения и помечает их как устаревшие. При выходе виджет останавливает запущенный им app-server.

Приложение показывает только **лимиты аккаунта**. Оно не считает токены, стоимость API или расход по чатам. Codex Quota не читает историю переписок, не сохраняет историю лимитов и не отправляет собственную аналитику. Для получения свежих данных нужен интернет.

## Установка на Mac

Готового установщика и скачиваемой сборки пока нет. Приложение нужно собрать на своём Mac:

1. **Установите Codex и войдите в аккаунт.** Если Codex CLI ещё не установлен, используйте [официальный установщик Codex CLI](https://learn.chatgpt.com/docs/codex/cli):

   ```sh
   curl -fsSL https://chatgpt.com/codex/install.sh | sh
   ```

   Затем запустите `codex` и войдите через аккаунт ChatGPT. Если Codex CLI уже доступен через настольное приложение Codex или ChatGPT, можно использовать его.

2. **Установите Swift 6 или новее.** Проверьте версию командой `swift --version`. Swift нужен для сборки приложения.

3. **Соберите и откройте приложение:**

   ```sh
   git clone https://github.com/DOFomintsev/codex-quota.git
   cd codex-quota
   ./scripts/build-app.sh
   open "dist/Codex Quota.app"
   ```

После сборки появится `dist/Codex Quota.app`. Проверьте приложение и при желании переместите его в «Программы». Сборка подписана локальной временной подписью и не нотариализована Apple Developer ID, поэтому macOS может попросить подтвердить запуск. Не отключайте Gatekeeper целиком.

Приложение работает на macOS 13 и новее. Проверено на Apple Silicon; Intel Mac отдельно не проверялся. Автозапуск не включается сам: при желании добавьте Codex Quota в **Системные настройки → Основные → Объекты входа**.

## Конфиденциальность и ограничения

- Виджет использует существующий вход в Codex через локальный app-server; пароль или API-ключ в самом приложении вводить не нужно.
- Приложение не читает переписки и не сохраняет историю лимитов.
- Протокол app-server и доступность данных о лимитах могут измениться с обновлением Codex. Аккаунт должен предоставлять лимит на 5 часов; вход только по API-ключу и все типы аккаунтов не проверялись.
- Это независимый инструмент сообщества, а не официальный продукт OpenAI.
